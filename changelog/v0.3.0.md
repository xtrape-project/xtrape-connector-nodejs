# v0.3.0 Changelog

Status: historical release-train notes for the v0.3 Agent SDK update.

## Theme

Contract alignment for the OpHub/capability metadata release train while preserving embedded SDK scope.

## Changed

- Updated contracts dependency to `0.3.x` and synchronized lockfile metadata.
- Imported `RuntimeKind` and `ActionPrepareResult` from contracts instead of mirroring local copies.
- Clarified embedded SDK scope and kept OpHub-specific runtime behavior out of the package.
- NPM publish workflow refined for tag-based release behavior.

## Compatibility

- Pairs with Opstage CE `0.3.x`, contracts-node `0.3.x`, demo `0.3.x`, docs, and site.
- Does not implement OpHub-managed local adapters; those remain in `xtrape-capsule-ophub-go`.
