# v0.2.0 Changelog

Status: historical release notes for the v0.2 Agent SDK update.

## Theme

Operational hardening for public preview users.

## Added

- Typed API errors and explicit retry classification for transport, server, registration, and authentication failures.
- Structured logger option alongside the console-shaped logger.
- Runnable examples and README documentation for typed errors, structured logging, and service metadata.

## Changed

- Retry behavior now avoids retrying operator-actionable registration/auth failures.
- Redaction behavior aligned with shared package expectations.
- Dependency and lockfile alignment with contracts-node `0.2.x`.

## Compatibility

- Pairs with the v0.2 release train across contracts, CE, demo, docs, and site.
