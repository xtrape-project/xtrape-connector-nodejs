# v0.1.0 Changelog

Status: historical release notes for the first Node embedded Agent SDK preview.

## Theme

Initial embedded SDK for outbound-only Capsule Service integration with Opstage CE.

## Added

- `CapsuleAgent` lifecycle with `start`, `stop`, and health execution helpers.
- Registration token exchange, Agent token persistence via file token store, heartbeat loop, service reporting loop, and command polling loop.
- Health provider, config provider, and action registration APIs.
- `ACTION_PREPARE` / `ACTION_EXECUTE` handling with default prepare payload generation from JSON schema defaults.
- Redaction helpers for logs and command/report payload context.

## Compatibility

- Pairs with Opstage CE `0.1.x` and `@xtrape/capsule-contracts-node@0.1.x`.
- SDK is embedded-agent only; OpHub-managed runtime is outside this repository.
