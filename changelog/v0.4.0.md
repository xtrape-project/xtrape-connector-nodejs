# v0.4.0 Changelog Draft

Status: draft until the v0.4 release train is tagged and accepted.

## Theme

Capsule Bus Experimental.

## Added

- Experimental `CapsuleAgent.publishBusEvent()` hook for v0.4 Capsule Bus trials.
- API client support for `POST /api/agents/{agentId}/bus/events`.
- Type aliases derived from contracts-node Capsule Bus schemas/responses to avoid local wire-shape drift.
- README and test coverage for the experimental publish hook.

## Notes

- Capsule Bus APIs are experimental and not stable before v1.0.
- The SDK only publishes events as an already registered embedded agent; routing and persistence remain CE responsibilities.
- Artifacts must be published from `v*` version tags only; prerelease tags map to prerelease/`next` artifacts where applicable.
