# Support

Community Edition support is best effort — no response-time or resolution SLA.

Once the public rollout executes (per the canonical support policy below), use
this repository's issue tracker on the public host (forgejo.xtrape.com) — or
the project role address published with that rollout — for reproducible bugs
and feature requests. Until that rollout there is no operating external
support channel. Use the private security channel for suspected
vulnerabilities. Never include
passwords, tokens, private keys, or unredacted personal data.
